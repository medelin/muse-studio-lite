# Changelog

## 2026-10-28 — Meta's advertising capabilities in full

- **All six objectives** (`studio/meta/objectives.py`): awareness (reach, ad recall), traffic (link clicks, landing page views), engagement (post engagement, messages on Messenger, Instagram or WhatsApp, event responses), leads (instant form, website pixel), app promotion (installs) and sales (website pixel, optionally a catalog). One table in code maps goal and sub-choice to objective, optimisation goal, billing event, destination type, promoted object, creative kind, call to action and the insights result; a test per row. Brief v1 gains `objective.sub` and `promotion` (pixel, event, app, store link, event id, catalog, product set, privacy page, form questions); a missing id is a field error, an id the owner never wrote is cleared from the draft. The payload's `delivery` block is signed with the rest and by hash (`spec_sha256` in the approval message); both adapters refuse a delivery that is not a table row or promotes another Page; `studio verify` rejects a campaign or ad set step, or a write, that names another mapping.
- **Lead ads**: the instant form (the owner's questions and own privacy-policy page; no notices added) is created through the Page's `leadgen_forms` before the creative; leads are polled from `/{form_id}/leads` (Leads page button, `studio leads-poll`) or pushed by a `leadgen` webhook accepted only with a valid `X-Hub-Signature-256` (refused without `META_APP_SECRET`); stored once per Meta lead id, mapped to the lead scorer's rule inputs, scored; receipts carry counts only.
- **Audiences** (`studio/meta/audience.py`): Advantage+ audience by default (age_min 18–25 control, age_max 65, the owner's range in `age_range`, genders and interests as suggestions); interest and language hints resolved to Meta ids by code through the targeting search and shown on the approval screen; country, interest and custom-audience exclusions; the owner's own custom audiences; a lookalike built under the campaign approval from the owner's source audience. No user data is uploaded.
- **Formats**: carousel of 2–10 Muse Image cards, a 9:16 video cut by code from the renders with shots ordered by `muse-wonder-1.0` (it reads images and writes text; it does not render video), uploaded through `advideos` with the reviewed poster as thumbnail, and copy A/B with every variant reviewed (dynamic creative where Meta supports it for the optimisation goal, else separate ads in one ad set; activation activates every ad). F1 gains the carousel and Reels video limits.
- **Measurement** (`studio/meta/measurement.py`): objective-aware insights (`results`/`cost_per_result`, the objective's action otherwise, reach, frequency, CPM, spend, CTR, inline link clicks, attribution setting) by age and gender, placement and region; `studio insights-pull` (hourly) or a button writes `insights.snapshot` receipts; code rules propose moves (costly placement, no results, fatigue, room to scale) that execute only through a new signed `campaign.update` approval and the executor; the analyst reads the measurement; `/report` shows it.
- **Account currency**: budgets are in the ad account's currency (read once from `/act_{id}?fields=currency,timezone_name`; the mock's is `STUDIO_ACCOUNT_CURRENCY`), sent in minor units by Meta's currency offsets; a brief in another currency is a field error; the ceiling (`STUDIO_MAX_DAILY_BUDGET`) is in that currency.
- Reviewers and the image scene of a Brief v1 run no longer judge or draw against the demo brand sheet: the brief's advertiser and confirmed statements replace it.
- Second example brief: this studio advertised as an open-source tool for one-person businesses (PL and EN, 6 GBP a day for 7 days, Poland), selectable next to the ceramics default; recorded replay set `muse`. A read-only recorded Graph cassette (`graph_readonly.json`: account currency, interest and locale search, insights fields, lead forms).
- Help: five EN/PL entries (objectives, lead ads, audiences, formats, measurement). Eval: 575/575 tampered exports rejected across 23 classes (new: objective changed after signing, promoted_object changed after signing, recommendation executed without approval), 204/204 attack tests.
