# Muse Studio Lite

**An AI ad agency in a box — Meta Muse agents draft, design and score; a human signs every send.**

Built for the Meta Global AI Developer Hackathon 2026 (Indie track · Build for Your World).

Small businesses run Facebook and Instagram ads, answer comments and chase leads by hand.
Muse Studio Lite turns that into one loop run by cooperating agents:

- **Inbox agent** — reads comments (text and images), triages intent, drafts the reply.
- **Studio agent** — turns a brief into ad copy and creatives (Muse Image, SAM 3.1 cut-outs).
- **Leads agent** — scores and routes leads to the CRM.
- **Human gate** — nothing leaves the system until a person signs the exact content.

Status: in active development during the event. I'm using it to make and run my own real ads,
and improving it as I go.
