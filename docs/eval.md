## 1. Tamper suite (`studio verify`)

Each case is a fresh ledger (random number of receipts, a signed reply approval, its adapter step and its write, a second run), exported and then tampered with. Verified with the ledger key, the approver registry and, for rollback, the latest known manifest seq. "The server itself" rows are logs signed with the real ledger key: what verify still catches if the server lies.

| Tamper class | Who could do it | N | Rejected |
|---|---|---|---|
| edited field | someone without the ledger key | 25 | 25 |
| re-hashed without the ledger key | someone without the ledger key | 25 | 25 |
| receipt deleted mid-run | someone without the ledger key | 25 | 25 |
| receipts reordered | someone without the ledger key | 25 | 25 |
| receipt duplicated | someone without the ledger key | 25 | 25 |
| tail truncated | someone without the ledger key | 25 | 25 |
